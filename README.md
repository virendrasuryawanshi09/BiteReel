# 🍔 BiteReel – Visual Food Ordering Platform

BiteReel is a modern food ordering web application built using the MERN stack.  
It focuses on a **visual-first experience**, where users explore dishes through short, reel-style videos instead of static menus — making food discovery faster and more engaging.

---

## 🚀 Features

- 📱 **Reel-Style Food Discovery**
  - Browse dishes using Instagram-like reels
  - Rich visuals improve decision-making for users

- 🔐 **Authentication & Security**
  - Secure login and registration using JWT
  - Password encryption with Bcrypt
  - Protected routes for authorized users

- 🛒 **Food Ordering System**
  - Add items to cart
  - Place orders with real-time updates
  - Order history tracking

- ⚡ **Performance Optimizations**
  - Lazy loading of components and images
  - Optimized API calls for faster response time

- 📊 **User-Friendly UI**
  - Responsive design for mobile and desktop
  - Clean and intuitive React-based interface
